One-time setup

Use the computer that will execute tasks

  1. Install Node.js 22+ and Ollama.
  2. Download the agent files and run npm install and npx playwright install chromium.
  3. Run ollama pull qwen2.5:3b. For screenshot-based PC control, also run ollama pull llava:7b.
  4. Run npm start and copy the bearer token shown in the terminal.
  5. In another terminal run cloudflared tunnel --url http://localhost:3920 and copy its HTTPS URL.
  6. Paste the tunnel URL and token above and select Save & connect. Keep both terminals open.
Cloud limit: a Quick Tunnel is temporary. Actual browser and desktop execution uses your PC; it is not an always-on cloud PC.

Prompts and page context go to Ollama on the connected runner; no hosted AI API is configured. The tunnel forwards traffic to your PC. Anyone with both its URL and token may control it, so disconnect after use. PromptPilot is not an official government service.
