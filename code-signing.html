PromptPilot — Code signing policy

Current status: the published Windows installer is unsigned.

The project has not yet received approval for a trusted signing certificate. We will describe a release as Authenticode-signed only after Windows verifies a valid signature and timestamp. Do not treat any current installer as signed.

Planned signing attribution

Only after approval, the planned attribution is: “Free code signing provided by SignPath.io, certificate by SignPath Foundation”. This is a planned route; SignPath Foundation has not yet approved the project.

What will be signed

Only the PromptPilot setup executable built from the public Mini-PC source repository by the Windows GitHub Actions workflow may be submitted for signing. Third-party tools, Node packages, Chromium, Ollama models and cloud services are not signed by PromptPilot.

Team roles

  • Committer and maintainer: Rohit-Singh-1991, the public repository owner.
  • Reviewer: the maintainer reviews changes; outside contributions should be submitted through pull requests and reviewed before merge.
  • Signing approver: the maintainer manually reviews every release-signing request.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Browser automation, prompt planning and desktop actions run locally. The hosted dashboard can reach the local agent only when the user starts the temporary tunnel and provides its URL and bearer token.

Third-party privacy information: Ollama, Cloudflare and npm.

Install and uninstall

The Windows wizard offers browser-only or full PC-vision installation. Uninstall through Windows Settings → Apps → Installed apps → PromptPilot Local Agent → Uninstall. This removes the PromptPilot installation folder and shortcuts; it does not remove independently installed Node.js, Ollama, Cloudflare Tunnel or the models downloaded into Ollama.

Verify a signed release

Get-AuthenticodeSignature .\PromptPilotSetup.exe | Format-List Status,SignerCertificate,TimeStamperCertificate
Get-FileHash .\PromptPilotSetup.exe -Algorithm SHA256

Expected status is Valid, with both a signer and timestamp certificate. A valid signature confirms signer identity and file integrity but does not guarantee immediate SmartScreen reputation.

Application status

Free signing through SignPath Foundation is subject to application review, a configured trusted build system and project, code-signing policy configuration, and manual approval for every release. The signing workflow will not publish an asset if signing credentials and project configuration are absent.
